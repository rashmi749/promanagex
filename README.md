# ProManageX – Project Management System

## About the Project

ProManageX is a project management system designed to help users organize projects, manage tasks, track progress, and improve productivity. The system provides a centralized platform for managing project-related activities efficiently.

## Objectives

- Organize and manage projects efficiently.
- Create and manage project tasks.
- Monitor project progress and deadlines.
- Improve team collaboration and productivity.
- Provide a user-friendly project management experience.

## Features

- Project Management
- Task Management
- Project Progress Tracking
- Deadline Management
- User-Friendly Interface
- Organized Project Dashboard

## Getting Started

### Prerequisites

- Visual Studio Code
- XAMPP
- A web browser
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Move the project folder into the XAMPP `htdocs` directory.

3. Start Apache and MySQL using the XAMPP Control Panel if required.

4. Configure the database if the project uses MySQL.

5. Open the project in your browser:

   ```text
   http://localhost/promanagex/
   ```
